# Translation catalogs

The Spanish catalog is an AI draft prepared for the first localization phase. It has not been reviewed by a native speaker, and it must not be described as reviewed.

Only the foundation and language-switcher strings are present. Legal and FAQ prose remains English in this phase.

Guidelines:

- Keys are the English source sentences.
- Preserve `:placeholders` exactly.
- Preserve plural branch counts.
- Use UTF-8 JSON without a byte order mark.
- The project does not allow em dashes or en dashes anywhere.
